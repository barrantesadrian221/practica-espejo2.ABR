# DevTask

Aplicación sencilla para gestionar tareas.

## Funciones

- Añadir tareas y asignarles prioridad.
- Filtrar tareas pendientes y completadas.
- Cambiar el estado de una tarea.

## Uso

1. Compila el proyecto con `tsc`.
2. Abre `index.html` con una extensión como Live Server.

Las tareas se guardan en memoria y se reinician al recargar la página.
